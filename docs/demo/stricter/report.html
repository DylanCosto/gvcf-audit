How to interpret this report

Callable means the input supplies haploid or diploid small-variant genotype evidence passing the stated filters, depth and GQ thresholds. It does not establish absence of every variant type or correctness of the caller. Indel/structural spans and overlapping records are conservatively unresolved.

    Ambiguous reference bases and overlapping records take precedence in base counts. The record limit includes those mismatches; the base limit counts only the primary status. A record is in scope when any part of its span overlaps a requested interval.
